A program that writes one joke about cats, one line, with a setup and a turn that lands: the cat knocks the phone off the table, watches it fall, then looks up at you like you dropped it.

The entry is one line of 97 characters, inside the event's 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
